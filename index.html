  2. 02

    ORGANIZE

    그룹과 단축키를 한곳에 묶습니다.

    HUD에서 현재 그룹, 실행 방식, 단축키와 스크립트 구성을 바로 확인합니다.

  3. 03

    INSPECT

    실행 전에 무엇이 나갈지 확인합니다.

    그룹을 선택하면 스크립트 구성과 설정이 별도 상세 그래프로 이어집니다.

  4. 04

    RUN LOCAL

    실제 입력은 Windows Runtime이 보냅니다.

    서버는 구성을 보관하고, 실제 키·마우스 입력은 현재 PC의 Runtime에서만 실행됩니다.

  5. 05

    STOP SAFE

    멈추는 길은 항상 가까이 둡니다.
