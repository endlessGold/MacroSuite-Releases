  1. 01

    DISCOVER

    필요한 매크로부터 찾습니다.

    공개 허브에서는 로그인 전에 이름, 설명, 사용하는 키와 버튼을 먼저 확인할 수 있습니다. 서버에 있는 것을 찾는 단계와 내 PC에서 실행하는 단계가 섞이지 않습니다.

    실제 허브 열기 →
  2. 02

    ORGANIZE

    그룹과 단축키를 한곳에 묶습니다.

    HUD를 펼치면 현재 그룹, 실행 방식, 단축키와 스크립트 수가 한눈에 나타납니다. PC를 바꿔도 이 구성은 계정에서 다시 동기화됩니다.

  3. 03

    INSPECT

    실행 전에 무엇이 나갈지 확인합니다.

    사냥 그룹을 선택해 스크립트 구성과 실행 상태를 확인합니다. 중요한 조작은 목록 안에 숨기지 않고 별도 상세 그래프로 이어집니다.

  4. 04

    RUN LOCAL

    실제 입력은 Windows Runtime이 보냅니다.

    서버가 원격으로 키를 누르지 않습니다. 앱이 최신 구성을 받아 현재 PC에서만 실행합니다. 실전 입력 상태는 HUD의 상태색과 문구로 구분됩니다.

  5. 05

    STOP SAFE

    멈추는 길은 항상 가까이 둡니다.

    전부 정지는 확인 대화상자 없이 즉시 안전한 방향으로 동작합니다. 실행이 끝나면 HUD가 다시 꺼진 상태를 명확히 보여 줍니다.
